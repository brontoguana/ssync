Full source-level security audit is not claimed. Filesystem containment uses Linux openat2 no-follow capabilities; a process with the same OS identity can alter the authorized tree, credentials and executable, so endpoint compromise remains outside the remote-peer boundary. Per-file replacement is atomic, not the entire tree. Failed updates preserve existing file contents; previously completed files/directories remain if a later file fails. Physical sparse-file preservation is not promised; sparse sources transfer correct logical content. Retained partials are private/credential-root-path-content bound, up to128 files and16GiB total prospective size per receiver root; operator cleanup may be required after repeated abandoned transfers. No automatic credential expiry.
